Key Data Flows
🤖 AI Career Recommendation
1
User submits profile (skills, interests, resume)
2
React → API Gateway /recommendations/generate
3
Lambda fetches resume from S3
4
Single GPT-4o call → career paths + match scores
5
Parallel DynamoDB writes (Recommendations table)
6
Response returned to React → rendered in dashboard
📄 Resume Upload & Analysis
1
User uploads PDF/DOCX via ResumeAnalysis.js
2
POST /files/upload → Files Lambda → S3 bucket
3
AWS Textract parses text & structure
4
POST /files/download → fetch parsed content
5
Analysis cached in sessionStorage
🔐 Auth & User State
1
Amplify signIn → Cognito User Pool
2
JWT ID token stored in Amplify session
3
storageService checks localStorage
4
If empty → loads from DynamoDB via /user/all
5
Changes debounced (2s) then synced back to DynamoDB
💼 Job Search
1
React calls jobSearchService.searchJobs()
2
Parallel fetch: Remotive + Arbeitnow APIs
3
Match scores calculated against user profile
4
Sorted by score, rendered in OpportunitiesSection
5
Deep-link buttons open job boards in new tab
▶️ Video Recommendations
1
VideoRecommendations.js triggers on career path change
2
POST to youtube-search Lambda
3
Lambda queries YouTube /search + /videos APIs
4
Stats, thumbnails & durations returned
5
VideoGrid renders cards with embed links
🧭 Career Simulation
1
User selects scenario in CareerScenarioSimulator
2
POST to Recommendations API (requestType: career_simulation)
3
GPT-4o generates salary projection + milestones
4
Response validated & salary capped at 50% increase
5
Results animated with Framer Motion
